Metodología

Cómo se construyó el escenario

1

Datos oficiales ONPE

Se toman actas contabilizadas, votos válidos nacionales y resultados por región desde la web de resultados.

2

Proyección regional

Para cada región nacional, se proyectan votos con una regla lineal: votos actuales / porcentaje de actas contabilizadas.

3

Extranjero ONPE + Datum

Si ONPE ya contabilizó votos del extranjero, se respetan esos votos oficiales. Datum se aplica solo al extranjero pendiente.
