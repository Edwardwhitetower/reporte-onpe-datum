Control de calidad

Actualización con validación técnica automática

El informe solo publica cortes cuando la fuente oficial entrega respuestas JSON válidas. Si ONPE devuelve HTML u ocurre un fallo de descarga, el sistema bloquea el corte y mantiene el último corte válido publicado.

Esta validación no altera los datos oficiales ni reemplaza los resultados de ONPE/JNE; solo evita publicar archivos incompletos o respuestas inválidas como si fueran data.

Metodología

Cómo se construyó el escenario

1

Datos oficiales ONPE

Se toman actas contabilizadas, votos válidos nacionales y resultados por ubicación geográfica desde la web oficial de resultados.

2

Proyección Perú

La proyección se calcula por provincia cuando los datos provinciales están disponibles; de lo contrario, usa regiones como respaldo.

3

Extranjero ONPE + Datum

Si ONPE ya contabilizó votos del extranjero, se respetan esos votos oficiales. Datum se aplica solo al extranjero pendiente.

Sensibilidad

Prueba de sensibilidad del volumen extranjero

Estos escenarios no son pronósticos independientes. Solo prueban cómo cambiaría el resultado si el volumen final de votos extranjeros válidos termina por debajo o por encima del estimado actual.
